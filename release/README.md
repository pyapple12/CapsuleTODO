# CapsuleTODO 使用说明

玻璃质感的桌面 Todo 看板——常驻桌面一角，随手记、随手勾。

---

## 快速上手

1. 把 `capsule-todo.exe` 放到任意文件夹（建议单独建一个，如 `D:\CapsuleTODO\`）；
2. 双击运行——首次启动会在 exe 同级自动创建 `configs\` 和 `data\` 两个文件夹（配置和数据都住这里，**不要删**）；
3. 玻璃小板出现在屏幕右上角，开始用吧。

> 本软件为绿色单文件版，无需安装、不写注册表；换电脑 = 整个文件夹拷走。

## 日常使用

### 待办清单

- **添加**：顶部输入框输入，回车确认（最多 12 字）；
- **勾选完成**：点条目左侧圆圈——条目播放勾选动画后收入归档；
- **归档自动清理**：已完成的条目在归档中保留 7 天，超时自动删除（不可恢复），归档板不会越积越长；
- **修改标题**：双击条目直接在行内编辑；
- **查看详情 / 写笔记**：单击条目正文打开详情板（可写笔记、看创建时间）；
- **删除**：条目右侧删除钮，点两次确认（第一次进入待确认态，再点执行）；
- **调整顺序**：按住条目拖动到想要的位置。

### 气泡（临时剪贴板）

- 在任何软件里**复制文字**后按全局热键（默认 **Ctrl + Alt + C**），内容自动收进气泡页；
- **选中文字直接按热键**也行——无需先复制（应用会自动帮你复制再收进来）；
- 气泡页里：**单击**看全文，**双击**复制回剪贴板，支持拖动排序；
- 攒满上限（默认 5 条，可在设置里调）会出现红色提醒，及时清理。

### 白板

一块随写随存的临时记事板，切换页签即可使用，内容自动保存。

### 窗口

- **拖动位置**：按住顶部标题栏区域拖；
- **双击标题**：缩回托盘（想彻底退出请看下方"退出"）；
- **贴边吸附 / 窗口置顶**：默认关闭，需要可在设置或托盘右键菜单里开启。

### 托盘图标

右下角托盘常驻图标：

- **悬停**：快速预览待办清单；
- **左键**：显示 / 聚焦主窗；
- **右键**：菜单（聚焦主窗 / 贴边吸附开关 / 窗口置顶开关 / 退出）。

## 设置

点右上角齿轮打开设置板：

| 设置项       | 说明                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------- |
| 跟随系统     | 开 = 主题随 Windows 深浅色自动切换（默认开）；关后可手动选浅色/暗色，选择会被记住（重启保持） |
| 气泡提醒数量 | 攒满多少条气泡时提醒清理（1 ~ 20）                                                            |
| 捕获热键     | 全局热键组合，点击后按下想要的组合即可录入；被占用会红字提示并回退                            |

## 数据与备份

所有数据都在 exe 同级的两个文件夹里：

- `configs\config.json`——窗口位置、气泡上限、热键等设置；
- `data\todo.db`——待办、归档、气泡、白板的全部内容。

**备份** = 把这两个文件夹复制走；**恢复** = 覆盖回来。

## 退出

- 点右键托盘图标 → **退出**，才会真正关闭程序（会自动保存窗口位置）；
- 双击标题 / Alt+F4 只是**缩回托盘**继续常驻，不是退出。

## 常见问题

**按热键没反应？**
该组合可能被其他软件占用了。打开设置换一个组合；仍不行时检查输入法或安全软件是否拦截了全局热键。

**换了新电脑 / 删了文件夹，数据没了？**
数据都在 exe 同级的 `configs\` 和 `data\` 里，随文件夹一起走；只拷 exe 不带这两个文件夹 = 全新开始。

**杀毒软件报毒？**
绿色单文件 exe 无数字签名，部分杀软会误报。本项目开源（GitHub: pyapple12/CapsuleTODO），可自行核对源码；添加信任即可。

**窗口不见了？**
多半是缩在托盘里——点托盘图标即可唤回；也可能记忆的位置在已拔掉的副屏上，重启应用会自动回到主屏默认位（右上角）。

**系统要求？**
Windows 10 / 11（64 位）。玻璃模糊效果依赖系统亚克力材质，Win10 部分旧版本观感会有差异。
