## 2. 配色逻辑（三条定律）

1. **单色相位**：全图所有颜色都在紫→品红相位区间（色相约 257°–350°），没有蓝、青、绿。界面同理：一切颜色从主薰衣草派生（加深/提亮/降饱和），不引入第二色相。
2. **无死黑死白**：最深是茄墨 `#572d41`，最亮是蜜桃白 `#ffd9c4`——文字用"梅墨"不用 `#000`，亮面用暖白不用 `#fff`，保持柔和的彩墨感。
3. **暖色只做光带**：珊瑚/蜜桃是地平线上的一条细光带，面积小、饱和度最高——对应界面里"小而亮"的元素：徽章、REC 按钮、焦点态。禁止大面积使用。

**比例（60-30-10 的暮色版）**：氛围底（壁纸 + 紫调纱）60% → 玻璃面板（中性白/黑纱）30% → 梅墨文字与结构 10% → 珊瑚点缀 ≤5%。

**对比度红线**（实测）：主薰衣草 `#a892dc` 上白字仅 2.7:1，不达标——它只作装饰色（辉光/滑块底/纱染）；需要承载白字的交互色（按钮底、焦点环上的文字）必须用其加深同相值 `#7a5fc4`（白字 4.9:1，色相不变）。

## 4. 渐变与染色配方

**天空渐变（壁纸/聚焦背景/加载氛围均可复用）**：

```css
linear-gradient(
  180deg,
  #a892dc 0%,
  #c6a5e1 40%,
  #f4bacb 65%,
  #ffd9c4 82%,
  #fc9b8b 100%
);
```

**玻璃紫染（进阶可选）**：浅色主题把中性白纱换成淡紫纱，融入更自然——
`--glass-bg: rgba(214, 196, 240, 0.3)`（由 `#a892dc` 提亮稀释）；暗色主题 `rgba(46, 28, 58, 0.35)`（酒梅方向）。

**辉光**：沿用现有 `color-mix(in srgb, var(--accent) 35%, transparent)` 配方，换 accent 即全量跟随，无需逐处改。

## 5. 使用守则

- **壁纸即配色的一半**：玻璃透底设计，背景直接参与成色——壁纸选暮色紫粉调（本图或同族），避免高饱和冷色壁纸破坏相位。
- **深浅主题取色方向**：浅色主题从色板亮端取（浅薰衣草/淡玫瑰）配梅墨字；暗色主题从深端取（酒梅/茄墨）配亮薰衣草字；accent 两态各用 §3 定值。
- **派生纪律**：需要新色时先从 `#a892dc` 出发加深/提亮/降饱和（`color-mix`），不得凭空引入新色相；珊瑚只允许出现在 ≤5% 的小面积强调处。
- **灰也要带彩**：中性灰一律用兰紫灰 `#a474a0` 系（`color-mix` 派生），不用纯灰 `#808080`。
