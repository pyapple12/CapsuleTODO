## 真实窗口可行性标注

- ✅ 半透明纱、亮边/rim/落影、accent 配色、面板玻璃、截断展示——内容无关绘制层，失焦/聚焦均有效；
- ⚠️ 聚焦磨砂预览（`backdrop-filter` 近似）：作用于**页面内背景图**，观感近似；真实窗口的聚焦磨砂由一期 DWM Acrylic 背板承担（已落地），落地时以真实窗口观感为准；
- ❌ 原型中浏览器直接模糊"窗外真实桌面"——OS 边界不可复现，实验场用背景图模拟桌面。

## 调参与落地规则

1. 调参只改 `glass.css` 令牌（含实验场扩展令牌 `--focus-blur`/`--radius-*`），改完刷新浏览器即时生效；
2. 定稿读数记录进本 README"基准配方读数"（追加式，保留历次定稿）；
3. 落回 `ui/` 需另立 PL：按映射表逐区块迁移，deep 深浅双主题 + 门禁七项全绿后才算闭环。
